# XBRL 2.1, Inline XBRL 1.1, and the Open Information Model

XBRL 2.1 remains the base specification that regulators' taxonomies use.
The Open Information Model 1.0 (Recommendation, 19 April 2023) defines the model behind the xBRL-XML, xBRL-JSON, and xBRL-CSV formats.
Inline XBRL 1.1 became an Edited Recommendation on 20 July 2026, clarifying reports that mix Inline XBRL and HTML documents.
Table Constraints for xBRL-CSV became a Recommendation on 10 September 2026.
Taxonomy Packages 1.1 is a Candidate Recommendation, not final; only Recommendations are final for software.

For a design:

- A report is valid only against the taxonomy version the regulator names for that period; pin the taxonomy, not only the specification
- Put a digest of the filed report and its taxonomy version in the evidence, never the report itself when it holds non-public figures before publication
