# EIP-6493 (Signature scheme for SSZ transactions)

A standard that defines how to sign a transaction represented in SSZ (the serialization format used by the consensus layer).

| Point | What the document says |
|---|---|
| What it decides | A scheme for signing transactions represented in SSZ directly |
| Required EIPs | EIP-6404, EIP-6466 |

## Current status

The document's status is `Draft`, and it was created on 2023-02-24.
It is not included in the Pectra meta EIP (EIP-7600), the Fusaka meta EIP (EIP-7607), or the `Scheduled for Inclusion` list of the Glamsterdam meta EIP (EIP-7773), and no list of the Hegotá meta EIP (EIP-8081) names it.

## Not yet shipped

It is not `Final` and is not live on mainnet.
