# x402 is run by the x402 Foundation; version 2 moved payments into HTTP headers

x402 lets a server answer a request with HTTP 402 Payment Required, and the client pays in a token on a chain and repeats the request. Coinbase released it in May 2025 and version 2 in December 2025, which moved the payment data into HTTP headers, names chains in the CAIP format, lets payment networks and facilitators be added as plugins, and adds sessions so an agent can pay repeatedly without authorizing every call. Coinbase moved the protocol to the x402 Foundation at the Linux Foundation, which began operating on 14 July 2026 with about 40 member organizations.

For a design:

- Give the paying agent its own key or permission with a spending limit per payment and per period, an allowlist of payees, and an expiry, never the owner's key
- Record each payment (payee, amount, chain, and request) for review, and let a person revoke the agent's permission
- Check which x402 version and facilitator the paid API uses before building on it
