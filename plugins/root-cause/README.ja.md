# Root Cause

バグの原因をエージェントに証拠から突き止めさせ、コードを変える前に原因を確かめさせます。直すのは症状ではなく原因です。

[English](README.md) · 日本語

バグを直すよう頼むと、エージェントは症状だけを消しがちです。nullの確かめ、やり直し、待ち時間を足したり、落ちるテストを外したりして、バグは別の形で戻ってきます。
このプラグインは、代わりに従う1つの手順をClaude CodeとCodexに渡します。
エージェントはバグを再現し、その時に通るコードを読み、仮説を1つずつ確かめて誤りかどうかを試してから、コードを変えます。
直すのは原因だけで、先に落ちるテストを書き、証拠と一緒に報告します。

```
症状を記録し、再現する
  ↓
再現の時に通るコードを読む
  ↓
実験で誤りと示せる形の仮説を3つまで挙げる
  ↓
仮説を1つずつ確かめ、誤りかどうかを試す
  ↓
落ちるテストを先に書き、原因だけを直す
  ↓
原因と証拠と直した内容を報告する
```

## インストール

```
/plugin marketplace add cardene777/agent-shuriken        # Claude Code
/plugin install root-cause@agent-shuriken

codex plugin marketplace add cardene777/agent-shuriken   # Codex
codex plugin add root-cause@agent-shuriken
```

## 使い方

このプラグインは、「このテストがたまにだけ落ちる。原因を調べて」のようにバグを伝えると始まります。
呼び出して始めることもできます。Claude Codeでは`/root-cause:root-cause`の後に何が失敗するかを続けて実行し、Codexでは`$`を入力して**Root Cause**を選びます。

1. 何が失敗するか、本来どうなるはずか、どう動かしたかをエージェントに伝えます。足りない時はエージェントが尋ねます
2. エージェントがバグを再現します。できればテストで再現し、その時に通るコードを読みます
3. エージェントが仮説を3つまで挙げ、1つずつ確かめ、それぞれが誤りかどうかを試します
4. エージェントが原因だけを直します。新しいテストが通り、今までのテストも通ること、直した所を元に戻すとバグが戻ることを確かめます
5. エージェントが、症状、原因とその証拠、直した内容、同じ原因が影響するほかの箇所を報告します

3通りのやり方で原因が見つからない時は、エージェントは推測で直さずに止まり、何を試してそれぞれで何が分かったかを報告します。

報告は次の形です。

```text
## デバッグの報告

### 症状
日付のテストが手元では通り、ビルドのサーバーでは落ちる。

### 原因
formatDay()がタイムゾーンを渡さずにtoLocaleDateString()を呼んでおり、動かしたマシンのタイムゾーンを使っていた。
証拠: 手元でもTZ=UTCでは落ち、TZ=Asia/Tokyoでは通る。

### 直した内容
formatDay()がtimeZoneを明示して渡すようにした。両方のタイムゾーンで動く新しいテストを足した。

### 影響する箇所
formatMonth()も同じ呼び方をしていたので、合わせて直した。

### 再発の防止
テストを常にTZ=UTCで動かすようにした。
```

## 必要な物

| ツール | 必要な時 |
|---|---|
| プロジェクトのテストを動かす道具 | バグを再現し、直したことを確かめる時 |
| `git` | `git bisect`でバグが入ったコミットを探す時 |

このプラグインはスクリプトを持たず、ほかに必要な物はありません。

## 読む物と実行する物と送る物

すべての手順、エージェントが変えてよい物、止まる時は、[仕組み](docs/how-it-works.ja.md)に載せています。
要点は次のとおりです。

- 作業しているプロジェクトのコード、テスト、ログを読みます
- プロジェクトのテストとコマンド、`git`、コードの検索を実行します。`git bisect`は未コミットの変更が無い時だけ動かし、最後に必ず`git bisect reset`で戻します
- ファイルを書き換えるのは、そのプロジェクトの中で、バグの再現、調査、修正に要る時だけです。足したログは報告の前に消します
- 頼まれない限り、コミット、プッシュ、プルリクエストの作成はしません
- プラグイン自身のスクリプトは無く、どこにも接続せず、ファイルも残しません。環境変数の値は表示しません
