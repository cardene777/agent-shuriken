# 用語の扱い

この文書は汎用の原則だけを持つ。
プロジェクト固有の用語表があれば、そちらを優先する。

## 原則

1. 分野で定着した用語を採用する。
2. 初出だけ説明し、以後の表記を固定する。
3. 日本語訳が標準でない語は原語または定着したカタカナを使う。
4. 直訳が別の概念を指す場合は、その直訳を使わない。

## どの語を落とし、どの語を使うか

**語の一覧は使う repo の用語表 (`CLAUDE.md` / `AGENTS.md` / `GLOSSARY.md`) が持つ**。
用語表が無い repo では、上流の `lint.py` の指摘と、上流の本文の「読み手が何のことか分からない言い回しは、ふだんの言葉に戻す」の 7 つの型を疑いの材料にして、直すかを文脈で決める。

ここに表を写さない。
写すと語を足した時に片方だけ古くなり、どちらが正しいか読み手が決められなくなる。

一覧に無い語を落としたい時は、使う repo の用語表に 1 行足す。
足す前に既存の文書へ当てて件数を見る = 日本語として正しい意味で使われる語を足すと、
偽陽性が勝って検査が信じられなくなる。
