# 問いと選択肢の書き方

この file は手元で書いた。 上流には無い。

2026-10-06 に、人に選択肢を見せて答えてもらう確認のシートの見本を作り直した時、人が差し戻した所と、直して通った形から書き起こした。
人に選んでもらう問いを書く時に読む。
確認のシートの問いと、チャットで人に出す選択肢の問いが対象になる。

## 問いは 3 つの部品でできている

| 部品 | 読み手が知りたいこと |
|---|---|
| 問いの 1 行 | 何を決めるのか |
| 問いの下の説明 | どんな場面の話で、何を決めるのか |
| 選択肢の名前と説明 | 選ぶと何が起きるのか |

下の 4 つのうち、1 と 2 は問いの下の説明を、3 は選択肢を、4 は問い全体の量を決める。

## 4 つの決まり

### 1. 問いの下の説明は、場面を先に書き、次に何を決めるかを書く

「何のための問いか」 だけを書くと、読み手はどんな場面の話かを自分で想像して補うことになる。
差し戻された説明は、どれもこの形だった。

| 直す前 | 直した後 |
|---|---|
| 直すべき所が、直されないまま取り込まれるのを防ぐための問いです。 | 作った物を受入条件と見比べると、満たせていない条件が見つかることがあります。<br>例えば10個のうち1個が満たせていない時、その1個をどう扱わせるかの問いです。 |
| 回し先の番号を書き間違えると、後回しにした条件がどこにも残りません。 | 問1のAで「別の課題に回す」を選ぶと、回し先の課題の番号を書きます。<br>その番号の課題が本当にあるかまで、機械に確かめさせるかの問いです。<br>問1でA以外を選んだ時は、答えなくて大丈夫です。 |

別の問いの答えが前提になる時は、どの答えの時に関係するかも書く。
関係しない答えを選んだ人は、その問いを飛ばせる。

### 2. 場面は数を入れた例で示す

「満たせていない条件が出た時」 のように抽象のまま書いた場面は、読み手が思い描けない。
「10個のうち1個が満たせていない時」 のように、数を入れた例を 1 つ置く。
[`explaining.md`](explaining.md) の 5 (抽象的な説明の直後に具体例を置く) を、問いに当てはめた形になる。

### 3. 選択肢の名前と説明は、それだけ読めば何が起きるか分かる言葉にする

作業の中だけで通じる番号や略称 (段 4 / step 19 / 出口 A) を、選択肢に使わない。
「このまま進む」 は、何がこのままで、どこへ進むのかが読めない。

| 直す前 (名前 / 説明) | 直した後 (名前 / 説明) |
|---|---|
| このまま進む / 段6と段7は飛ばして次の段へ | 作り始める / 実装の計画へ進む |
| 受入条件を直す / 段4へ戻る (段19と段5ももう一度通る) | 受入条件から直す / 受入条件を書き直してから、もう一度このシートを見る |
| 設計だけ直す / 段19へ戻る (受入条件はそのまま) | 設計だけ直す / 受入条件はそのままで、設計だけ書き直す |

番号は、答えを記録する側 (貼り付ける文章や Issue の comment) に残す。
人が読む側には出さない。

### 4. 前提は短くし、問いは 3 つ前後に絞る

前提に一覧を全件並べると、問いに辿り着く前に読む力が尽きる。
受入条件の 19 行を前提に並べた版は「この19項目とか何？」 と差し戻された。
直した版は、前提を「いま」 と「おすすめを全部選ぶと」 の 2 つの箱に絞った。

1 つの問いに見えても、決めることが複数あれば分ける。
「この仕様で実装へ進めてよいか」 の 1 問だった版は、中身の判断 2 問と「作り始めてよいか」 の 1 問に分けて通った。
5 問を超えるなら、論点を絞ってから出す。

## 問いの言葉の5つの決まり

| 決まり | 例 |
|---|---|
| 物の名前は、画面のどこにある何かが読み手に判る粒度で書く | 「本文」→「GitHubのIssueの説明文」 |
| 作業の中で作った語は初出で中身を書き、日常語で済むなら置き換える | 「課題の型」→「Issueごとに選ぶ進め方（通し・画面なし・軽微）」 |
| 誰が何をどこにするかの主語と目的語を書く | 「型は課題ごとに1つで」→「Issueを起票した人かAIは、Issueごとに進め方を1つ残します」 |
| 要らない読点を入れない | 「課題の型は、どこに書きますか」→「進め方はどこに書きますか」 |
| 英単語と数字の前後に空白を入れない | 「13 件」→「13件」 |

問いを書く時は、上の5つも守る。

## 書いた後に確かめること

| 確かめること | 当たったら |
|---|---|
| 問いの下の説明が「〜ための問いです」 だけで終わっていないか | 場面を書いた 1 文を先頭に足す |
| 場面に数を入れた例が 1 つ在るか | 「例えば」 で始まる 1 文を足す |
| 選択肢の名前と説明に、作業の中だけの番号や略称が入っていないか | 選ぶと何が起きるかの言葉に置き換える |
| 前提が問いより長くないか | 一覧を外し、判断に要る差だけを残す |
| 問いが 2 つ以下で、1 つに決めることが複数入っていないか | 決めることごとに問いを分ける |
