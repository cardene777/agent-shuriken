# Sources

Every rule in the four pattern files names its sources by ID in its Sources row.
This file holds each source once, with the page it comes from, its kind, the day it was read, and a short quote from it.
The kinds are design systems, research and articles, public guidance, and accessibility.
Quotes are copied word for word from the page, in the page's own language, and `...` marks a cut.
A page read through the Internet Archive is linked by its original address.
The IDs start with the letter of the pattern file that cites them, `d-` for details, `l-` for lists and tables, `i-` for input and confirmation, and `s-` for states and notices.
