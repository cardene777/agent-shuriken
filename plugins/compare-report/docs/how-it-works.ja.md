# Compare Reportの仕組み

[English](how-it-works.md) · 日本語

このページには、エージェントが従う手順、レポートに入る物、あなたが読む前に確かめる物、ファイルを置く場所を載せています。
手順の本体は`skills/compare-report/SKILL.md`にあり、そこから参照するページは`skills/compare-report/references/`にあります。

## 手順

| 手順 | 誰が | 何が起きるか |
|---|---|---|
| 候補を挙げる | エージェント | 題材でWebを検索し、10〜15の候補をそれぞれ1行の説明と一緒に挙げます |
| 候補を決める | あなた | 候補を残す、足す、外すを決めます。比べるのはふつう3〜8個です。同じ問いで、表紙に載せる作者名を伝えるか、載せないことを選びます |
| 観点を選ぶ | エージェント | 性能、費用、信頼性、使いやすさ、周りの道具、リスクのように、題材に合う評価の観点を5〜8個示します |
| 観点を決める | あなた | 観点をそのままにするか、直します |
| 調べる | エージェント | 候補ごとに、公式の情報、数値、使っている所、リスクを集め、すべての主張に出典と日付を付けます。Claude Codeでは候補を並べて調べます |
| 書く | エージェント | レポートの型を埋めます |
| 確かめる | エージェント | レポートの確かめを動かして出た所をすべて直し、公平さと食い違いが無いかを読み直します |
| 印刷する | エージェント | 目次に各節のページを載せたPDFを作り、レポートを開きます |
| 直す | あなたとエージェント | 直してほしい所を伝えると、エージェントがHTMLとPDFを直します |

## レポートに入る物

| 節 | 中身 |
|---|---|
| 表紙 | 題名、比べた物、候補と観点と出典の数、日付、伝えた時は作者名 |
| 要約 | 比べる理由、上位3つの推奨、5〜7個の分かったこと |
| 候補 | 全候補の表と、強みと弱みを1つずつ書いた候補ごとのカード |
| 観点ごとの節 | 全候補の点数と判定の根拠を並べた表、数値がある時の棒グラフ、データの出どころの注記 |
| リスク | リスクごとの深刻さ、和らげる手、判定の根拠 |
| 順位 | すべての点数と総評を並べた採点表と、第1の推奨、代わりの案、控えの案と、それぞれを選ぶ条件 |
| 出典 | 引いた順に番号を付けたすべての出典と、読んだ日 |

PDFの目次では、各項目を点線でつなぎ、その節が始まるページ番号を添えます。表紙を除く各ページの下にもページ番号を入れます。
ページは表紙を1ページ目として数え、PDFの閲覧ソフトの数え方と揃えます。
HTMLの目次には番号を付けません。

点数はS(とても良い)からD(弱い)までの5段階です。
比べられる数値が無く、ある観点で公平に判定できない候補は、推測せず「採点しない」と書きます。

## データを正しく保つやり方

- 公開されていない数値は「非公開」と書きます
- 計った条件が違う数値は注記し、比べられる物のように1つのグラフへ並べません
- 提供元の主張と第三者の計測は分けて書きます
- すべての主張に、番号を付けた出典を引きます

## あなたが読む前に確かめる物

`scripts/check-report.py`は、次のすべてが満たされるまでレポートを通しません。

- 型の差し込み箇所が残っていない
- ネットから何も読み込まない。URLからスクリプト、スタイルシート、Webフォント、画像を読み込まない
- 要約、候補、リスク、順位、出典の節があって中身が入っており、観点ごとの節が1つ以上ある
- 点数かリスクの段階を含む表には、すべて判定の根拠の列がある
- 点数の文字と段階が合い、リスクの段階が書かれ、棒グラフの幅が0%から100%の間にある
- 出典の節が1つ以上のページへリンクしている
- 表紙の作者の行は、空で隠れているか名前が入っており、空白だけではない

## ファイルを置く場所

レポートごとに`~/.local/share/compare-report/<題材>-<日付>/`のフォルダーを作り、`report.html`と`report.pdf`を置きます。
別の場所に置く時は`COMPARE_REPORT_HOME`を設定するか、置くフォルダーをエージェントに伝えます。
フォルダーはあなただけが読め、既にあるレポートは上書きしません。

表紙に載せると伝えた作者名は、同じ場所(`~/.local/share/compare-report/`か`COMPARE_REPORT_HOME`)の`author.txt`に、あなただけが読める形で残します。
空のファイルは、名前を載せないと選んだことを表します。
エージェントは次のレポートで残した答えを最初の案にし、名前を忘れるよう頼むとファイルを消します。
名前はあなたの答えからだけ取り、`git config`、システムのユーザー名、アカウントからは取りません。

## 実行する物と接続する先

- エージェントのWeb検索とWebページの読み込み。検索には、題材と、候補と提供元の名前だけを使います
- レポートを確かめる`python3`
- PDFにするための、既に入っているChromium系のブラウザー(Chrome、Chromium、Edge、Brave)。画面に出さずに動かし、使い捨てのプロフィールは終わったら消します。使うブラウザーは`COMPARE_REPORT_BROWSER`で選べます
- ページ番号を求める`python3`。`scripts/toc-pages.py`が、ブラウザーが1回目のPDFに書いた行き先から各節のページを読み、番号を足したレポートの写し`.print-*.html`をレポートの隣に書きます。写しは印刷した後に消し、各節が同じページのままの時だけ新しいPDFで1回目のPDFを置き換えます。ページが分からない時は、題名だけの1回目のPDFを残し、理由を1行出します
- レポートを見せるための、macOSの`open`かLinuxの`xdg-open`

このプラグインは何もインストールせず、作るレポートはネットから何も読み込みません。
