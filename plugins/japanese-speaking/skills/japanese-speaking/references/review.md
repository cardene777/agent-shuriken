# 別の読み手へ渡す指示

この file と台本だけを、書いた会話を引き継がない読み手に渡す。
読み手には次の文をそのまま渡す。

---

次の台本を、1行ずつ声に出して読んだつもりで聞いてください。
人が実際に話しているように聞こえない行を探します。
台本を読んでいる、書いた文を読み上げている、と聞こえる行が対象です。

見る点は次のとおりです。

- 話し手どうしが相手の言葉を受けて話しているか。前の行と関係なく、自分の番の文を読んでいるだけになっていないか
- 相づち、相手の語の繰り返し、「ね」「よ」が、人が話す時と同じくらい入っているか
- 1人の話し手が専門家役になり、ほかの話し手が質問を出すだけの形になっていないか
- 言い切りすぎていないか。伝え聞いた事が「ようです」「ということです」で受けられているか
- 縮約 (「ちゃう」「じゃあ」) や、書き言葉 (「である」「であり、」) が混ざっていないか
- 文が助詞で途中で切れていないか。問いが「か」を落としていないか
- 話し手の意見が全部そろい、同じことを言い合っているだけになっていないか
- 3人以上で話す時、段の中で一度も話さない話し手がいないか
- 同じ言い回しや同じ文末が続いていないか。受けの行が毎回同じ相づちで始まっていないか
- 相手が言ったばかりの事や、読み上げた所を、ほぼ同じ言葉で言い直していないか
- 「ね」「よね」が毎行に付いていないか
- 1つの行に「所」「こと」「ある」のような中身の無い語が重なっていないか
- 前の話題と同じ型のたとえを繰り返していないか
- 話題の締めが、直前の相手の発言を受けているか

返す形は、問題のある行ごとに1行です。

```
L<行番号> <どう聞こえるか> → <どう言えば人が話しているように聞こえるか>
```

問題が無い時は `なし` とだけ返します。
台本に無い事実、数字、名前を、直す案に足さないでください。
