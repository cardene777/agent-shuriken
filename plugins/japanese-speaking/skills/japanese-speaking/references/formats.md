# 形式ごとの組み立て

書く前に形式を1つ選び、段ごとに誰が何を話すかを並べてから書く。
段は目安で、材料が無い段は飛ばす。

## ニュースを読み上げて話す

1人がニュースを読み、続けて2人でそのニュースについて話す。

1. 読む人が、何が起きたか、誰が出したか、主な数字と結果を続けて読む。伝え聞いた事は「〜ということです」「〜としています」で受ける
2. 相方が反応する。驚いた所、気になった所を、相方の言葉で言う
3. なぜ大事かを話す。用語は知っている話し手が話の流れの中で説明する
4. まだ分からないこと、条件、限界を話す
5. 2人の見方の違いを1つ入れる
6. 誰の役に立つかで締める

読み上げは事実を全部言い、話し合いの段で新しい事実を足さない。
NPR は掛け合いの1項目を「何が起きたか」「背景となぜ大事か」「まだ分からないことと次に起きること」で組む。

## 雑談

番組の始めや合間の短い話。

1. 挨拶と日付の後に、「ニュースの前に、」のように雑談に入る合図を言う
2. 話題を1つ出し、相方が自分の言葉で受ける
3. 2回から4回やりとりし、相づちと「ね」「よ」で受ける
4. 本題へ戻る一言で終える

## 対談

聞き手と話し手が1つの話題を掘る。

1. 聞き手が話題と話し手を紹介する
2. 聞き手は聞き手の代わりに問い、話し手の答えの語を繰り返して受ける
3. 話し手の答えは長短を散らし、聞き手が要点を言い直す
4. 聞き手が分かったことを短くまとめて終える

## 1人の語り

ナレーション、ひとり語りのポッドキャスト、動画の読み上げ。

1. 結論か、聞き手に向けた問いから始める
2. 1文に1つの情報で進め、「〜んです」「〜ですよね」で聞き手に話しかける
3. 段の切れ目で「で、」「そういえば」のように話題を変える合図を言う
4. 要点を1文で言い直して終える

## 話す原稿

発表、挨拶、説明会で人が読み上げる原稿。

1. 最初に何の話かと結論を言う
2. 段ごとに「1つ目は」「次に」で今どこを話しているかを示す
3. 数字と固有名詞は繰り返して言う
4. 最後に結論を言い直す
