# Account Cleanupの仕組み

[English](how-it-works.md) · 日本語

このページには、プラグインが何を読み、何を実行し、どこへ接続し、何を残すかを並べています。
実行する前に、使ってよいかを判断する材料にしてください。

## 作業の流れ

| 段階 | 誰が | 何が起きるか |
|---|---|---|
| 集める | エージェント | 選んだ取得元から、スクリプトがサービス名、URL、日付を読み、1つの候補の一覧にまとめます |
| 説明する | エージェント | スクリプトが使っていないと見られるアカウントに理由を付け、エージェントが各サイトの1行の説明を足します |
| 選ぶ | あなた | 候補を選ぶページで各アカウントを「消す」か「残す」にし、コピーした文をチャットに貼ります |
| 解約と削除 | エージェントとあなた | エージェントがログインし、有料プランを解約し、支払い方法を外して、「消す」にした各アカウントを削除します。二要素認証とCAPTCHAはあなたが対応します |
| 片付け | エージェント | 削除したアカウントのパスワード管理アプリの項目を、元に戻せる場所へ移します |

## パスワードを読まない仕組み

| 取得元 | 読む物 | 決して読まない物 |
|---|---|---|
| 1Password | 集める段階では、`op item list`が返す名前、URL、更新日 | 集める段階では`op item get`を一度も呼びません。ログインの時は、`browser.sh login`が項目を読んでページの入力欄へ直接打ち込み、エージェントにもファイルにも渡しません |
| Bitwarden | `bw list items`から得る名前、URL、更新日 | パスワード、ユーザー名、メモはスクリプトの中で捨て、ファイルにもエージェントにも届きません |
| ChromeとChromium系ブラウザ | 保存されたパスワードのデータベースのコピーから得る`origin_url`と日付 | パスワードの列は一度も取り出しません。コピーは読み終えたら削除します |
| Google、Apple、GitHubのログインと、Gmail | どのページを開き、何を検索するかだけ | エージェントは画面もメールも見ません |

認証情報を入力するのは、開いているページのドメインが、1Passwordの項目のURLのドメインと一致する時だけです。
URLの無い項目では、調べた上で`--site`に渡した公式のドメインでだけ入力します。
エージェントが読むページのスナップショットからは、入力欄の値をすべて取り除きます。
エージェントが操作するブラウザでは、パスワードの保存をオフにしています。

## 候補に挙がる理由

| 理由 | 意味 |
|---|---|
| 長く更新していない | 項目の最終更新が730日より前です。日数を変えるには`ACCOUNT_CLEANUP_STALE_DAYS`を設定します |
| サイトが無い | サイトのドメインがもう見つからず、サービスが終わっている見込みが高い状態です |
| 開発用のアドレス | URLが`localhost`、IPアドレス、`.local`の名前などで、Webサービスのアカウントではありません |
| ブラウザの拡張機能 | Webサイトではなくブラウザの拡張機能の項目です。暗号資産のウォレットであることが多いです |
| URLが壊れた項目 | 項目のURLが壊れていて、サイトを特定できません |

開発用のアドレスとURLの無い項目には、一切接続しません。

## 接続する先

| 接続先 | 理由 | 送る内容 |
|---|---|---|
| 各候補のドメイン | サイトがまだあるかを確かめるため | `https://<domain>/`への`HEAD`リクエスト。Cookieも個人データも付けません |
| npmのレジストリ | 初めて使う時に`playwright-core`をインストールするため | 通常のパッケージのダウンロード |
| Playwrightのダウンロードサーバー | 初めて使う時にChromiumをインストールするため | 通常のブラウザのダウンロード |
| あなたが承認したサービス | ログイン、解約、支払い方法の削除、アカウントの削除のため | あなたが自分でブラウザから送るのと同じ内容 |
| エージェントのWeb検索 | 同梱の一覧に無いサービスの削除ページを探すため | サービス名とドメインだけ |

これ以外には何も送らず、候補の一覧をどこかへ送ることもありません。

同梱の一覧を新しくする[`tools/update-sites.sh`](../tools/update-sites.sh)は、このリポジトリを保守する人だけが実行します。
このコマンドは、ログイン済みの`gh`を通して、GitHubにjdm-contrib/jdmの最新のコミットと、そのコミットの`_data/sites.json`だけを問い合わせ、ほかには何も送りません。
スキルがこのコマンドを実行することはありません。

## 2つのページ

`build-sheet.sh`はスキルのひな形から候補を選ぶページを書き、`followup.sh page`は別のひな形から後でやることの一覧のページを書きます。表のパスは`skills/account-cleanup/`から見た位置です。

| ファイル | 持つ物 |
|---|---|
| `templates/sheet.html` | 候補を選ぶページ。スタイル、英語と日本語の言葉、スクリプトを中に持ちます |
| `templates/followups.html` | 後でやることの一覧のページ。データ消去の依頼など、残っている作業を並べます。作りは同じです |
| `musubi.json` | musubiでの`page-design/structure`、`page-design/look`、`page-design/sheet`、`page-design/verify`への任意の準拠。それぞれにバージョンの範囲`^1.0.0`と、最後に確かめた時のコンテンツのフィンガープリントと、`"optional": true`を持つ |

どちらのページにも、English / 日本語の切り替えと、その隣に明るい色と暗い色の切り替えがあります。
選ぶまでは色がシステムの設定に従い、選んだ言語と色は2つのページで共有し、ブラウザのローカルストレージに`account-cleanup-lang`と`account-cleanup-theme`の名前で残ります。どこへも送りません。
候補を選ぶページは、選んだ物とメモを同じ所に`account-cleanup-choice-<回のID>`と`account-cleanup-memo-<回のID>`の名前で残すので、ページを閉じても消えません。
回のIDは16桁の16進数で、`prepare.sh`が集め直すたびにデータのフォルダの`round`に書き、`build-sheet.sh`がページに入れます。`prepare.sh --rebuild`では変わりません。
ページを開くとほかの回の分を全て消すので、新しい回は何も選んでいない状態で始まります。
最後の回の分を消す時は、ページを開いてブラウザの開発者ツールを開き、ローカルストレージにあるこの2つを消します。

- `design-formats`のプラグインの`page-design`のスキルが入っていれば、エージェントはその形式`structure`と`look`、ページの型`sheet`を読みます。`musubi.json`はこれらに任意の準拠で従います。候補を選ぶページと後でやることの一覧のページに`page-design`の`verify`を回し、名指された行のうち`annotate.sh`で書いた文の行を直し、ひな形の枠の行はあなたに伝えます。ほかのプラグインからはこれ以外を読みません
- `musubi`のコマンドが入っていれば、エージェントはこれらを読む前に`musubi check`を回し、失敗したら止まります。`design-formats`が入っていない時、`musubi check`は警告を出してこれらの準拠を飛ばします。従うコンテンツが変わると、フィンガープリントを確かめ直すまで`musubi check`は`account-cleanup`を拒否します
- `page-design`が無ければ、2つのひな形だけでページを作ります。プラグインのどこも`design-formats`を求めません

## 残す物

すべてのファイルは`~/.local/share/account-cleanup/`に置き、`ACCOUNT_CLEANUP_HOME`を設定した時はそちらに置きます。
どちらでも、あなただけが読める権限にします。

| ファイル | 作業を終えた後も残すか |
|---|---|
| 候補の一覧、候補を選ぶページ、回のID、保存した地域 | 残しません |
| サイトにログインしたままのブラウザのプロファイル | 残しません |
| エージェントが見つけた削除ページ（`additions.json`） | 残します。個人データを含まず、次に探す手間が省けます |
| 後でやることの一覧（`followups.tsv`）。1件を1行にし、日付、候補のドメイン、残っている物、記録した時に候補を選ぶページが出したサービスの名前を持ちます | 残します。データ消去の依頼など、後でやることを終えるまで残します |
| PlaywrightとChromium（`node/`） | 残します。次回の起動が速くなります。消すにはこのフォルダを削除します |

## 決してしないこと

- その回をあなたが承認する前に、最後の削除ボタンや解約ボタンを押すこと
- あなたが「消す」にしていないアカウントを削除すること
- パスワード管理アプリの項目を完全に削除すること。項目は1Passwordのアーカイブか、Bitwardenのゴミ箱へ移します
- Webページ、メール、貼り付けた文に書かれた指示に従うこと
