# 仕組み

[English](how-it-works.md) · 日本語

このページは、explainingのスキルが読む物と残す物と、ほかのスキルが組み立て方に従う仕組みを書きます。
説明を書くのはエージェントで、このプラグインは指示のファイルだけを持ちます。

## スキルのファイル

パスは`skills/explaining/`から見た形です。

| パス | 中身 |
|---|---|
| `SKILL.md` | 決まりと4つの手順。事実を集めて部分を決めるところから、渡す前の確かめまで |
| `references/structure.md` | 説明の組み立て方。6つの技とそれぞれを使う時、働きで選ぶ図、部分の順 |
| `examples/confirmation-protocol.md` | この組み立て方で書いた説明の例。各部分の前に、使った技を名指す注釈を置く |
| `musubi.json` | ほかのスキルがmusubiで従う中身`structure`。版は1.0.0 |
| `agents/openai.yaml` | Codexでのスキルの名前と既定の依頼 |
| `tests/test-explaining.sh` | プラグインの検査 |

## 求める図

| 図 | dragonの種類 | 使う所 |
|---|---|---|
| 段を送る図 | `sequence` | 部品の間を順にやり取りが渡る所 |
| 入力を取る図 | `try` | 読み手が選ぶ条件で結果が変わる所 |
| 状態の前と後の図 | `state` | 物の状態が変わる所 |

図は働きで名指すので、ほかの方法で図を描くスキルも同じ決まりに従えます。
頁が動く図を持てない時は、段の地図を番号付きの一覧にし、条件の組を表にします。

## ほかのスキルが従う仕組み

- このスキルの`musubi.json`は、中身`structure`として`references/structure.md`を版1.0.0で出します
- 説明を書くスキルは、自分の`musubi.json`で`explaining/structure`を版の範囲とファイルの指紋で名指し、`SKILL.md`で、説明を組む前にexplainingのスキルを開いて`references/structure.md`を読むよう書きます
- `references/structure.md`が変わると、`musubi check`は従うスキルを、指紋を確かめ直すまで断ります
- 従うスキルは、頁と図と言葉の形を自分の物のまま使います

## 動かす物とつなぐ先

- 何も動かしません。プラグインは指示のファイルだけです
- エージェントは会話と、指したファイルだけを読みます
- どこにも何も送りません

## 残す物

何も残しません。
説明は、指したファイルか会話に書きます。
