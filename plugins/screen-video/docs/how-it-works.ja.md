# Screen Videoの仕組み

[English](how-it-works.md) · 日本語

この頁は、流れの通し方と撮り方、動画の編集の仕方、各ファイルの置き場を説明します。
ここに書いたことは全て`skills/screen-video/scripts/screen-video.sh`が行います。このスクリプトは、Node.jsとPlaywrightとffmpegで`screen_video.mjs`を動かします。

## 動かすための道具

初めて使う時、`screen-video.sh`は`playwright-core` 1.65.0と`ffmpeg-static` 5.3.0を、データのフォルダの`node/`へ`pnpm`で入れます。`pnpm`が無ければ`npm`を使います。続けて、PlaywrightのヘッドレスのChromiumを入れます。
2回目からはそこにある物を使い、何も入れません。
読み上げる流れは、初めての時にその声の道具をデータのフォルダの`voices/`へ入れます。中身は[読み上げと曲と音](#読み上げと曲と音)に書きます。
ffmpegは次の順で選び、どれを使うかは`screen-video.sh doctor`が示します。

| 順 | 使うffmpeg |
|---|---|
| 1 | `SCREEN_VIDEO_FFMPEG`に書いたパス |
| 2 | `PATH`にある`ffmpeg`。libx264付きで作られた物に限ります |
| 3 | `ffmpeg-static`が取得した物 |

## 通す

`rehearse`は1920x1080のヘッドレスブラウザを開き、録画せずに操作を順に行います。
押す、打ち込む、選ぶ操作の直前には、押す所を囲んだ頁の画を保存します。ほかの操作の後には、頁をそのまま保存します。
`effect`を持つ最初の操作の手前で止まるため、流れを書いている間に送信や支払いは起きません。その操作と後の操作は、通していない印になります。
押す所が時間内に見つからない時は、その時の頁を保存し、探した物を添えてその操作を失敗の印にし、後の操作を通していない印にします。

`storyboard.html`は、上に流れの計画と印の付いた操作を、その下に操作ごとのカードを並べます。カードには画と、通したかどうかと、字幕と、操作の内容が載ります。
英語と日本語を切り替えられ、画を押すと大きく開きます。
`rehearsal.json`は同じ結果をエージェント向けに残します。

## 撮る

`record`は同じ操作を、画面を毎秒30コマで撮るブラウザで行います。
ポインターは少し曲がった道で押す所へ動き、近づくほど遅くなります。遠い所と小さい所ほど時間を掛けます。
押すと、押した所に輪が広がり、ボタンが一瞬沈みます。打ち込みは1文字ずつ、揃わない間で入ります。
各操作の前に、出ている字幕を読み終え、その声が終わるまで待つため、編集で字幕を途中で切らずに済みます。
`settled`を持つ`wait`は、頁がその秒数だけ変わらなくなった時点で次へ進みます。答えが少しずつ届く画面に使います。
各操作の始まりと終わりと、押す所の枠と、ポインターの道を`timeline.json`に書きます。
時刻は動画の最初のコマから数えるため、輪と字幕は押した瞬間に出ます。

流れの`mask`に挙げた値は、出た時点でぼかし、頁が変わるたびにぼかし直すため、全てのコマでぼけています。
`{"css": ...}`はセレクタに合う要素を、`{"text": ...}`はその文字を含む要素と入力欄をぼかします。

## 編集

| 動画 | 作り方 |
|---|---|
| `captioned.mp4` | 字幕を下に置きます。操作が押すか打ち込む所の枠に被る時は、上に置きます。読み上げと音も付けます |
| `edited.mp4` | 撮った動画をテーマの枠に収め、カード、寄り、頁の溶け込み、画面の下の字幕、読み上げ、曲、音を付けます。中身は下の節に書きます |
| `vertical.mp4` | 同じ物を1080x1920で作ります。撮った動画から切り出した9:16の窓が、枠の中で操作ごとに横へ動き、その下に大きめの字幕を置きます |
| `edited.gif` | `edited.mp4`を毎秒12コマ、幅960ピクセルにし、その動画の色から作った色の表で書きます |

`edit.json`は編集の組み方を並べます。テーマ、枠、カード、字幕、早送りの区間、溶け込み、寄り方、キーを押した時刻、各操作の位置です。
`remake`は、サイトを開かずに`raw.mp4`と`timeline.json`から、読み上げと全ての動画を作り直します。見た目、読み上げ、曲、カード、計画した長さは、その時の流れに従います。

### 動き

押す、打ち込む、選ぶ操作ごとに0.9秒掛けて滑らかに寄り、操作の間は画面全体へ戻ります。
寄るのは、押す所を目立たせるのに1.25倍以上の拡大が要る時だけで、1.6倍を超えません。大きなボタンはそのまま見せます。
押して別の頁が開く時は、新しい頁が0.6秒掛けて溶け込み終わるまで寄ったままにします。
読む字幕の無い1.2秒より長い待ちは、切らずに2倍から8倍で早送りし、画面の右上に印を出します。

### 見た目

撮った動画は、テーマの背景の上で角の丸い窓に収まり、柔らかい影が付き、その下の帯に字幕が出ます。
流れの`title`は最初の題のカードに、各操作の`chapter`はその操作の前の章のカードに、`end`は題とアドレスと一言を載せた締めのカードになります。
カードは撮った動画に足した止まった画の上に出るため、操作を隠しません。
テーマは、プロジェクトの`.screen-video/themes/<name>.json`、同梱の`themes/`の順に探し、`default`に重ねます。

### 読み上げと曲と音

| `voice.engine` | 声の作り方 |
|---|---|
| `local` | 英語はKokoro、日本語はVOICEVOXで、手元のマシンで作ります |
| `kokoro` | kokoro-js 1.2.1とKokoro-82Mのモデル。初めての時にデータのフォルダの`voices/kokoro/`へ入れます |
| `voicevox` | `voices/voicevox/`のPythonの環境に入れたVOICEVOX CORE 0.16.4と、その声のモデル、ONNX Runtime、辞書。利用者が規約に同意したと流れに書いた後でだけ、初めての時に取得します |
| `openai`、`elevenlabs`、`azure`、`google` | その会社で作ります。鍵は流れの`envFile`か環境変数から読み、字幕の文をその会社へ送ります |

各行の声は撮る前に作り、どの道具でも同じ大きさに揃えて、`voice/`と`voice.json`に残します。
VOICEVOXの声は、締めのカードと`credits.txt`に`VOICEVOX:<キャラクター名>`と表記します。
曲はffmpegで作る静かな和音で、読み上げの間は下がり、終わると戻ります。`music`でプロジェクトの曲のファイルを代わりに指定できます。
押すたびとキーごとに、`data/sounds/`に同梱したKenneyのUI Audio(CC0)の短い音が鳴ります。出所は[告知](../THIRD_PARTY_NOTICES.md)に載せています。

### 長さを合わせる

`seconds`がある時は、まずカードを短くし、それでも長ければ、待ちと字幕の無い間をさらに早送りします。最大で16倍です。
字幕の読む時間とその声は、普通の速さのまま残します。
それでも計画から1割より離れる時は、`record`と`remake`が何秒長いか短いかを示します。

### 見比べる

`compare`は`compare/compare.html`を書きます。寄り、ポインター、枠、読み上げ、長さなど、編集の点ごとに1つの区画を持ちます。
各区画は、撮ったままの動画と編集済みの動画を並べ、その点が見える時刻から再生します。
`--before <folder>`を付けると、撮ったままの動画の代わりに以前作った編集済みの動画を並べ、編集の2つの版を見比べます。

## ログイン

| `login`の項目 | 使い方 |
|---|---|
| `basic` | HTTPのベーシック認証のユーザー名とパスワード。`envFile`のenvファイルか環境変数から読み、ブラウザへ渡します |
| `session` | `login`が保存したCookieとストレージ。最初の操作の前にブラウザへ読み込みます |

`env`を持つ`fill`の操作は、その変数の値を打ち込みます。値は出力にも台本にも`timeline.json`にも出ません。
`login`はブラウザの窓を開き、あなたがログインし終えるまで待ちます。アドレスが`--until`の文字を含むか、窓を閉じた時点で、ログインを権限600の`sessions/<project>--<session>.json`へ保存します。

## フォルダ

| 物 | 置き場 |
|---|---|
| データのフォルダ | `$SCREEN_VIDEO_HOME`、`$XDG_DATA_HOME/screen-video`、`~/.local/share/screen-video`の順。あなただけが読めます |
| 流れの動画 | `<データのフォルダ>/<project>/<流れの名前>/`か、`--out`で指定したフォルダ |
| 通した結果 | 流れのフォルダの中の`rehearsal/` |
| あなたが撮った動画から作った物 | `<データのフォルダ>/<project>/<動画の名前>/` |

プロジェクトは`.screen-video/flows/`を持つフォルダで、その名前はフォルダの名前です。
動かすたびに、まずそのフォルダを空にします。消すのは自分が書く動画、画、音、`voice/`、`compare/`、JSON、SRT、HTML、テキストのファイルだけで、ほかの物があればその名前を挙げて止まります。

## あなたが撮った動画

`scenes`は、動画の場面が変わる所ごとの画を`scenes/`へ、その時刻を`scenes.json`へ保存し、3秒以上動きの無い区間を`freezes.json`に並べます。
エージェントは画を読み、`captions.json`を書きます。
`render`はその字幕を動画に焼き込み、動きの無い区間を両端0.5秒ずつ残して切った編集済みの動画も作ります。
