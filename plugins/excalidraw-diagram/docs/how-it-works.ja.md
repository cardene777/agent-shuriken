# Excalidraw Diagramの仕組み

[English](how-it-works.md) · 日本語

このページでは、プラグインが読む物と書く物、スクリプトによる図の配置の仕方、確かめるすべての決まり、SVGとPNGの作り方を説明します。
ここに書いたことは全部`skills/excalidraw-diagram/scripts/`のスクリプトが行い、Pythonの標準ライブラリだけを使います。
命令は`excalidraw_diagram.py`で、ほかのファイルが仕様の読み取り、テーマ、配置、確かめ、手描きの線と書体を含むSVGの作成、PNGの作成、Mermaidの変換を受け持ちます。

## 命令

| 命令 | すること |
|---|---|
| `build <spec.json か diagram.mmd>` | 仕様を読み、配置し、確かめ、`<名前>.excalidraw`、`<名前>.svg`、`<名前>.png`を仕様の隣か`--out`のフォルダに書きます。名前は仕様のファイル名か`--name`から取ります |
| `check <file.excalidraw>` | どのExcalidrawのシーンも下の決まりで確かめ、何も変えません |
| `render <file.excalidraw>` | Excalidrawのエディタで編集したシーンなどから`<名前>.svg`と`<名前>.png`を書きます。シーンは変えません |
| `mermaid <diagram.mmd か ->` | Mermaidの文を仕様に変え、画面に出すか`-o`のファイルに書きます |

`--png auto`(既定)はPNGを作れる時に作り、`--png skip`は作らず、`--png require`は作れない時に終了コード4で終わります。
`--scale`はSVGの1ピクセルに当てるPNGのピクセル数で、1、2(既定)、3のどれかです。

| 終了コード | 意味 |
|---|---|
| 0 | 終わりました |
| 1 | 確かめに通らなかったか、矢印やラベルの置き場所がありませんでした。何も書いていません |
| 2 | 入力が正しくありません。JSONの誤り、仕様の誤り、範囲外のMermaid、シーンでないファイルのどれかです |
| 3 | 「置き換えないファイル」に書いた理由で、置き換えてはいけないファイルが既にあります。何も書いていません |
| 4 | `--png require`を付けたのにPNGを作れませんでした。ほかのファイルは書いています |

## 仕様

エージェントは仕様をJSONで書きます。スクリプトは、知らないキー、存在しないid、下の一覧に無い値を断り、問題を一度に全部示します。

| キー | 値 |
|---|---|
| `type` | `graph`(既定)か`sequence` |
| `title` | 任意の題です。図の上に28 pxで描きます |
| `theme` | `sketch`(既定)、`hatch`、`pencil`、`soft`、`marker`、`dark`、`clean`、`friendly`のどれかです。「テーマ」で説明します |
| `direction` | グラフだけで使います。`down`(既定)か`right` |
| `order` | グラフだけで使います。`auto`(既定)は、交わる矢印が減る時に段の中のノードを並べ替えます。`listed`は仕様の順をそのまま保ちます |
| `style` | 任意です。`clean`はテーマの線を直線に、文字をHelveticaにします。`sketch`は手描きにします |
| `fill` | 任意です。`solid`か`hachure`で、テーマの塗りを置き換えます |
| `node_gap` | 1つの段の中のノードの間隔です。40から400で、既定は60です |
| `tier_gap` | 段と段の間隔です。60から600で、既定は80です |
| `nodes` | `id`、`label`と、任意の`lines`、`shape`(`box`、`ellipse`、`diamond`、`table`)、`color`、`group`、`tier` |
| `edges` | `from`、`to`と、任意の`label`、`line`(`solid`、`dashed`、`dotted`)、`head`(`end`、`both`、`none`) |
| `groups` | `id`、`label`と、任意の`color`と`tier` |
| `participants` | シーケンスだけで使います。`id`、`label`と、任意の`lines`と`color` |
| `messages` | シーケンスだけで使います。`from`、`to`と、任意の`label`、`line`(`solid`、`dashed`)、`head`(`end`、`none`) |

色は`gray`(既定)、`blue`、`green`、`red`、`orange`、`yellow`、`violet`、`teal`で、それぞれ輪郭の色、図形の塗り、囲み用の淡い塗りを持ちます。
1つの仕様に書けるのは、ノード80個と矢印160本まで、または参加者20人とメッセージ160個までです。文字は1行120字までです。

## テーマ

テーマは見た目を決めます。線の描き方、文字の書体、図形と囲みの塗り方です。
仕様の`theme`で選ぶか、1回の組み立てだけ`build --theme`で選びます。どちらも無い時は`sketch`です。
すべてのテーマは`skills/excalidraw-diagram/themes.json`に定め、配置とSVGはすべての設定をここから読みます。

| テーマ | 粗さ | 書体 | 塗り | 輪郭 | 背景 |
|---|---|---|---|---|---|
| `sketch` | 1 | Excalifont | 図形の色 | 色付き、2 px | 白 |
| `hatch` | 1 | Excalifont | 図形の色の斜線 | 色付き、2 px | 白 |
| `pencil` | 1 | Excalifont | 無し。囲みも塗りません | 黒、1 px | 白 |
| `soft` | 1 | Excalifont | 淡い色。囲みは塗りません | 色付き、2 px | 白 |
| `marker` | 2 | Excalifont | 図形の色の斜線 | 色付き、4 px | 白 |
| `dark` | 1 | Excalifont | 図形の色 | 色付き、2 px | Excalidrawの暗い表示と同じ暗い背景 |
| `clean` | 0 | Helvetica | 図形の色 | 色付き、2 px | 白 |
| `friendly` | 1 | Nunito | 図形の色 | 色付き、2 px | 白 |

粗さはExcalidraw自身の設定で、0は直線、1はエディタの既定の手描きの線、2はもっと粗い線を描きます。
矢印とそのラベルは濃い灰色の`#495057`で2 pxです。`pencil`では黒で1 pxです。
仕様の`style`と`fill`はテーマを調整します。`"style": "clean"`は線を直線に、文字をHelveticaにし、`"style": "sketch"`は手描きにし、`fill`は塗りを置き換えます。
ファイルはテーマごとに1つのオブジェクトを持ち、キーは`roughness`、`font`、`fill`、`tint`、`zone_fill`、`outline`、`shape_stroke`、`line_stroke`、`line_color`、`dark`です。スクリプトはすべての値を確かめ、誤りがあればその設定を示して終了コード2で止まります。

## グラフの配置の仕方

1. 各ノードは、SVGが描くように1行目を太字にした文字の周りに、少なくとも20 pxの余白ができる大きさにします。箱は少なくとも160×60 px、楕円は140×60、ひし形は140×80で、大きさは10 px単位に切り上げます。ひし形は文字が中央の半分にしか収まらないため、文字に要る幅と高さの2倍にします。`table`は、ラベルの見出しの下に、左寄せの行を並べた白い本体を置きます。続けて、箱とテーブルを最も広い物の幅へ、自分の幅の半分まで広げます。文字が許す限り1つの図の箱が同じ幅になり、縦の列が揃います
2. 文字はフォントのファイルを使わずに測ります。文字の種類(細い字、幅の広い字、大文字、東アジアの字。東アジアの字は1字を1 emと数えます)ごとの平均の幅に6 %の余裕を足すので、見積もりが実際の文字より小さくなることはありません
3. 各ノードに段を決めます。仕様に書いた段か、そのノードへ矢印を向けるノードのうち最も深い物の1つ下の段です。輪を閉じる矢印はこの数え方から外すので、輪の最初のノードが上に残ります
4. 1つの段のノードは仕様の順から始め、同じ線の上で中央に揃え、間に`node_gap`、段と段の間に`tier_gap`を空けます。間にラベルを置く必要がある時は、矢印に沿ったラベルの長さに48 pxを足した幅まで広げます。下向きの段は上端で、右向きの段は左端で揃えます
5. `order`が`auto`の時は、続けて隣り合う段の間で交わる矢印が減るように段を並べ替えます。下への一巡では、各ノードを上の段でつながるノードの平均の位置へ動かし、上への一巡では下の段で同じことをします。そうしたつながりが無いノードは場所を保ち、位置が同じノードは仕様の順を保ち、一巡の組を最大4回繰り返します。囲みへのつながりは、その中のノードの位置で数えます。新しい順は、仕様の順より交わりが少ない時だけ使うため、交わりの無い図は順を保ちます。`listed`の時はこの手順を飛ばします
6. グループは、まず囲みの中で同じように配置し(囲みの中の段も同じように並べ替えます)、その囲みを1つの項目として外側の配置に加えます。そのため、囲みどうしも、囲みと外のノードも重なりません。囲みはノードの周りに50 pxを空け、ラベルを左から16 px、上から10 pxに置き、ラベルが収まる幅にします

## 矢印の描き方

- 矢印は相手の図形に向いた辺から出て、両端は輪郭の5 px外で止まります。道筋は12 px外から引きます。流れに逆らう矢印は、両端が寄っている側を回ります。両端が平均して図の中央より左にある時は左、それ以外は右です(流れが右向きの時は上か下)。逆向きの矢印への返事の時は、代わりにその横を並べて走らせます。同じノードへ戻る輪は、流れを横切る向きに出て戻ります
- 同じ辺を使う矢印は、辺に沿って間隔を空けて並べます。向かい合う2つの辺が同じ矢印だけを持つ時は、出入りの位置を揃えて矢印をまっすぐにします。ひし形は角ごとに1つしか出入りの位置を持たず、余った矢印は相手のいる側の空いた角へ移ります。箱の1つの辺から、それぞれ別の図形へ出る矢印は、辺の中央から出て1本の線を共にし、木の枝のように分かれます。この時は互いに沿って走っても費用を払いません
- 両端の間は、水平と垂直の線に沿って道筋を決めます。使う線は、各図形の辺を10 px広げた線、図形の間の隙間の中央の線、出入りの位置を通る線です。道筋は最も安い経路で、1ピクセルにつき1(図形の辺の線の上では1.25)、曲がり1回につき40、ほかの矢印と同じ線を走ると1歩につき400と重なった1ピクセルにつき4、囲みの破線の輪郭に沿って走ると1ピクセルにつき3、先に引いた矢印と交わるか、その端から8 px以内を通る点1つにつき150がかかります。矢印は短い物から順に引きます。曲がる位置は両端の中ほどを好みます
- 曲がる矢印は`roundness: null`で書くので、Excalidrawのエディタは曲線に滑らかにせず、角のとがった直線の区間で描きます
- ラベルは、まず矢印の最も長い直線の区間の横に、線から8 px離して、中央から順に外へずらしながら置きます。水平の区間なら上か下、垂直の区間なら右か左です。図形の輪郭に触れず(囲みの中に丸ごと入るのは構いません)、囲みの破線の輪郭から内外とも10 px離れ、ほかの文字(4 px)とどの線(3 px)からも離れた場所だけを使います

図が確かめに通らない時、スクリプトはまず同じ間隔のまま、交わりの費用を外して矢印を引き直します。1本の矢印を避けると、ほかの2本が1つの線に押し出されることがあるためです。
それでも矢印かラベルの置き場所が無い時、スクリプトは間隔を1.5倍、次に2.25倍にして配置し直し、そう伝えます。
それでも無い時は、終了コード1で止まり、その矢印を示します。

## シーケンス図の配置の仕方

参加者は同じ高さで横一列に並び、少なくとも60 px、間のラベルが収まるだけ離します。
それぞれに破線の生存線を引きます。
メッセージは上から1行に1つずつ、生存線の間の水平な矢印で描き、ラベルは矢印が最初に通る隙間の中央、矢印の上に置きます。
自分へのメッセージは、生存線の右の小さな輪で描き、ラベルをその横に置きます。
Excalidrawは矢印を線ではなく図形に結び付けるため、メッセージの矢印は結び付けません。

## 確かめ

確かめは仕上がったシーンに対して行い、プラグインが書いたファイルでも、Excalidrawのエディタで編集したファイルでも同じです。
問題は、図形をその中の文字で示します。

| 決まり | 問題になる時 |
|---|---|
| `format` | 要素にidが無い、同じidが2回使われている、位置か大きさが数でない、文字の要素に文字か文字の大きさが無い、矢印か線の点が2つ未満 |
| `reference` | 文字、結び付け、`boundElements`の項目が、存在しない要素か、指し返さない要素を指している |
| `overlap` | 片方がもう片方を含むのではなく、2つの図形が重なっている |
| `spacing` | 入れ子でもなく、同じExcalidrawのグループでもない2つの図形の間が40 px未満 |
| `zone-padding` | ほかの図形を含む図形(囲み)が、中の図形のどれかとの間に50 pxを空けていない |
| `text-fit` | 図形に結び付けた文字が中の場所より大きい。場所は図形から各辺5 pxを引いた物で、楕円とひし形はその内側に入る最大の長方形から同じだけ引いた物です |
| `text-center` | 図形に結び付けた文字が、中央に揃える向きで図形の中央から2 pxより離れている |
| `font-size` | 16 px未満の文字がある |
| `text-overlap` | 自由な文字が図形の輪郭をまたいでいる(輪郭から4 px、囲みの輪郭からは輪郭の上にあるように見えないよう8 px離して、丸ごと内側か丸ごと外側にある必要があります)か、2つの文字が重なっている |
| `label-on-line` | 矢印か線が、自由な文字か、自分の物ではない矢印のラベルを横切っている |
| `arrow-through` | 矢印か線が、囲み以外の図形を通り抜けている |
| `arrow-end` | 矢印の端が図形の内側にある、結び付けた図形から4 px未満、または30 pxより離れている |
| `unbound` | 矢印の端が図形から30 px以内にあるのに結び付いておらず、図形を動かしても付いてこない |
| `curve` | 点が3つ以上ある矢印か線がroundnessを持ち、Excalidrawが曲線として描いてしまう |
| `arrow-overlap` | 2本の矢印か線が、同じ水平か垂直の区間を2 pxより長く並んで走っている。ただし、1つの図形の1点から出て一緒に走り、分かれる1本の幹の2本は除きます |

警告は確かめを失敗にはしません。`crossing`は、交わるか触れている矢印の組をすべて示し、その点の数を伝えます。交わる点、片方がもう片方の上で終わる点、3 pxより近づく点を数えます。1本の幹の2本は、幹に沿った所と分かれる所で接しますが、その点は数えません。交わりを避けられないグラフもあるため、`build`と`check`は終了コード0のまま、組ごとに`Warning: crossing:`で始まる行を出します。

次の注意も、確かめを失敗にはしません。1行の文字しか持たない箱、文字に比べてずっと大きな図形、絵文字を含む文字、確かめの対象外の種類の要素(画像、フレーム、手書きの線)です。

## ファイルの中身

`.excalidraw`のファイルは、Excalidrawのエディタが保存するJSONの形式で、`type`、`version` 2、`source`、`elements`、`appState`、`files`を持ちます。
どの要素も、エディタ自身が書く項目をすべて持ちます。

- 要素のidは仕様から作ります。`node:<id>`と`node:<id>:text`、テーブルの本体は`node:<id>:fields`、`zone:<group>`、`edge:<n>`と`edge:<n>:label`、`participant:<id>`、`message:<n>`、`title`です
- 図形の中の文字は図形に結び付けて(`containerId`)、図形と一緒に動くようにします。矢印と囲みのラベルは、その矢印か囲みとグループにします
- Excalidrawの文字の要素は、すべての行に1つのフォント、大きさ、太さを使うため、エディタではノードの名前と詳しい行が同じ見た目になります。名前を太字にするか、太字の無い書体で細い縁取りを付けて太くするのはSVGとPNGだけです
- 矢印は両端を`focus` 0、`gap` 5で結び付け、図形の`boundElements`にも載せるので、図形を動かすと付いてきます
- 箱と囲みは角を丸め、Excalidrawの丸みの大きさを箱は最大8 px、囲みは最大16 pxにします。テーブル、ひし形、楕円は丸めません。文字はテーマの書体で、Excalidrawのフォント5(Excalifont)、6(Nunito)、2(Helvetica)のどれかです。矢印の先端は塗りつぶした三角です
- `dark`のテーマのシーンは`appState.theme`を`dark`にし、SVGとPNGはそれを読んで暗く描きます
- 乱数の種はidから作り、時刻は固定するので、同じ仕様からは常に同じファイルができます
- 最上位の`generator`の項目に、要素、`appState`、`files`のSHA-256の要約を入れます。エディタは保存する時にこの項目を落とすので、ファイルが編集されたことが分かります

## SVGとPNG

SVGは、スクリプトがシーンから24 pxの余白とシーンの背景色で描きます。
長方形、楕円、ひし形、文字、矢印とその先端、線を描き、ほかの種類の要素は描かずに名前を示します。
粗さが0より大きい要素は、Excalidrawのエディタがrough.jsというライブラリで描くのと同じように手で描きます。まっすぐな線は少し曲げて2度なぞり、丸い角と楕円は制御点で揺らし、塗りつぶしは輪郭を少し緩くした写しにし、斜線の塗りは-41度に並べた粗い線で描きます。式はrough.jsに沿い、乱数はすべて要素の種から取るので、同じシーンからは常に同じSVGができます。粗さが0の要素はすっきりした輪郭で描きます。
図形の中の文字の1行目(ノードの名前)は太字にします。太字の無いExcalifontとNunitoでは、文字と同じ色の細い縁取りを付けて太くします。
ExcalifontかNunitoの文字は、要るフォントのファイルを`skills/excalidraw-diagram/data/fonts/`から読んでdata URLで埋め込むので、どのマシンでも同じ見た目になり、ネットワークも要りません。日本語のようにそれらのフォントに無い文字は、見る人のマシンに既にあるフォント(日本語のフォントを含むサンセリフの一覧)を使います。Helveticaの文字もその一覧を、Excalidrawのコード用フォントは等幅の一覧を使います。
`appState.theme`が`dark`のシーンは、SVG全体にCSSのフィルター`invert(93%) hue-rotate(180deg)`を掛けます。Excalidrawの暗い表示が使うのと同じフィルターです。
SVGの2行目は、残りの部分のSHA-256の要約を書いたコメントです。

PNGは、既に入っているブラウザが撮るSVGの画面写しです。
ブラウザは次の順に探します。

1. `EXCALIDRAW_DIAGRAM_BROWSER`のパス。値が`none`の時はPNGを作りません
2. Playwrightが`~/Library/Caches/ms-playwright`か`~/.cache/ms-playwright`に既に置いた`chrome-headless-shell`
3. macOSでは`/Applications`か`~/Applications`、Windowsではいつものインストール先、または`PATH`にあるGoogle Chrome、Chromium、Microsoft Edge

ブラウザは画面無しで動き、システムの一時フォルダに作った新しいプロファイルを使い、終わると削除します。裏での通信、同期、拡張機能、クラッシュの報告を止め、すべてのホスト名の名前解決が失敗する決まりを付けます。
開くのは手元のSVGだけで、窓の大きさをSVGの大きさにし、`--scale`を画面の倍率に使います。どちらかの辺が16000 pxを超える時は倍率を下げます。
PNGは、ブラウザが90秒以内に終わり、画像がちょうど期待した大きさの時だけ残し、画像のデータのSHA-256の要約を書いた文字の塊を付けます。
ブラウザが見つからない時や撮影に失敗した時は、`PNG skipped:`の後に理由を示し、`.excalidraw`のファイルとSVGはそのまま書きます。

## 置き換えないファイル

`build`と`render`は、書く前に、既にある出力のファイルを1つずつ見ます。

| ファイル | 尋ねずに置き換える時 |
|---|---|
| `.excalidraw` | `generator`の要約が中身とまだ一致する時。つまり、プラグインが書いた後に誰も保存も編集もしていない時です |
| `.svg` | 要約のコメントが残りの部分とまだ一致する時 |
| `.png` | 文字の塊が画像のデータとまだ一致する時 |

ほかのファイルが既にある時は、何かを書く前に終了コード3で止まり、エージェントがあなたに尋ねてから`--replace`を付けて実行し直します。
`render`は、読んだ`.excalidraw`のファイルを書きません。
`mermaid -o`は、`--replace`が無ければ既にあるファイルを置き換えません。
ファイルは同じフォルダの一時ファイルに書いてから名前を変えるので、書き込みに失敗しても書きかけのファイルは残りません。

## 残す物

| 何を | どこに | いつまで |
|---|---|---|
| 仕様、`.excalidraw`のファイル、SVG、PNG | 選んだフォルダ。プロジェクトでは多くの場合`docs/images/`です | あなたが消すまで |
| PNG 1枚のためのブラウザのプロファイル | システムの一時フォルダ | PNGを作り終えるか、失敗するまで |

ほかには何も書かず、設定や履歴も残しません。

## Mermaidの範囲

フローチャートは`flowchart`か`graph`と、`TD`、`TB`、`LR`で始めます(`BT`と`RL`は断ります)。

| Mermaid | 仕様 |
|---|---|
| `A[text]`、`A(text)`、`A[(text)]`、`A[[text]]`、`A{{text}}`、`A>text]` | 箱 |
| `A([text])`、`A((text))` | 楕円 |
| `A{text}` | ひし形 |
| 括弧の中の`"引用した文字"`と`<br>` | 括弧を含む文字と改行です。最初の行がラベル、ほかの行が`lines`になります |
| `-->`、`---`、`-.->`、`-.-`、`==>`、`===`、`<-->` | 矢印、先端の無い線、破線の矢印、破線、矢印、線、両端に先端のある矢印 |
| `-->|label|`、`-- label -->`、`-. label .->`、`== label ==>` | ラベル付きの矢印 |
| `A --> B --> C`、`A & B --> C` | 組ごとに1本の矢印 |
| `subgraph id [Title]` ... `end` | グループ。1段の深さまでです |
| `classDef`、`class`、`style`、`linkStyle`、`click`、`%%`のコメント、`%%{init}%%` | 読み飛ばし、注意に名前を出します |

シーケンス図は`sequenceDiagram`で始めます。

| Mermaid | 仕様 |
|---|---|
| `participant A`、`participant A as Label`、`actor A as Label` | 参加者 |
| `A->>B: text`、`A-->>B: text` | 矢印のメッセージ。実線か破線 |
| `A->B: text`、`A-->B: text` | 先端の無いメッセージ。実線か破線 |
| `A-)B`、`A--)B` | 矢印のメッセージ。実線か破線 |
| `autonumber`、`title Text` | 番号付きのラベルと、題 |
| `activate`、`deactivate`と、矢印の後の`+`と`-` | 読み飛ばし、注意に名前を出します |

ほかの物、例えば`loop`、`alt`、ノート、`x`か`o`で終わる矢印、入れ子のsubgraph、ほかの種類の図は、行番号を示して変換を止めます。

## しないこと

- 何かをダウンロードやインストールする、MCPのサーバーやコンテナを起動する、ネットワークを使う
- 図、仕様、コードをどこかへ送る
- 自分が書いていないファイルや、書いた後に変わったファイルを、`--replace`無しで置き換える
- 確かめや書き出しを頼まれたシーンを変える
- Excalidrawのコードを写す。プラグインは自分のコードで公開されたファイル形式を書きます。`data/fonts/`のフォントのファイルは、Excalidrawが配るExcalifontとNunitoのファイルを手を加えずに写した物で、SIL Open Font Licenseに従い、`THIRD_PARTY_NOTICES.md`に記録しています
