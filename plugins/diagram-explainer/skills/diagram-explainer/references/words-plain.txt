# Words to flag in Japanese documents written for general readers. Pass this file with `--words`
# to `prose.py`, `check.py`, or `figure.py`.
#
# The difference from `prose-words.txt` is the reader, not the quality of the word:
#   prose-words.txt  words no reader understands (meeting-room phrasing)
#   this file        words ordinary in the field but unknown outside it
#
# Technical documents do not pass this file, so their katakana words for "endpoint" or "request"
# are not flagged. A document with its own term table passes both (`--words` can be repeated):
#   python3 scripts/prose.py <document.html> --words data/words-plain.txt --words <its table>
#
# The format is the term-table format (`word -> replacement` or `word → replacement`, and
# `allow:` lines), not the three-column format of `prose-words.txt`.
