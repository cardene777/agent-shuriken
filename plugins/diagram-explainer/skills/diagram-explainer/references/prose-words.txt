# Words the prose check flags in Japanese documents. `prose.py` reads this file, and `figure.py`
# reads the default-matched kinds through `prose.default_words()`. None of these words is used on a
# document whose `<html lang>` does not start with `ja`.
#
# Format: `kind  word  replacement`, separated by spaces. The replacement is shown in the check's
# output; spaces inside it are joined back with one space.
#
# The first column is the kind, and prose.py reads the kinds from this file.
# Kinds with their own handling in prose.py:
#   wordy           Phrases that can be dropped or shortened without changing the facts. Also words
#                   that leave the judgement to the reader ("various", "many"), with a hint to be concrete.
#                   Matched before the phrases allowed by a term table are removed.
#   jargon          Words no reader understands. Proper names used correctly (products, standards) are
#                   not listed. Merged with the term table; `--no-default-words` turns it off.
#   logbook         Words about the state of the work. Only words that never appear in a sentence that
#                   states the design. Matched before the allowed phrases are removed.
#   bare-english    English words written outside backticks. Matched on word boundaries, ignoring case.
#   worker-heading  Words that mark a heading written for the person making the document. Matched in
#                   headings and `<summary>` only. The third column is not used.
#   allow           English words never flagged as bare-english. The third column is not used.
# Every other kind is matched the default way: a substring match on the text after removing the
# phrases a term table allows. A new kind added here is checked without any change to the scripts.
#   coined          Made-up Japanese words used where the field has an established term.
#
# Phrases allowed in a single document belong in that document's term table (`allow:` lines), not here.
