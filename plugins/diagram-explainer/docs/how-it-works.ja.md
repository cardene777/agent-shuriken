# Diagram Explainerの仕組み

[English](how-it-works.md) · 日本語

このページには、エージェントが踏む手順、資料に入る物、あなたが見る前に確かめる物、ファイルを置く場所を載せています。
手順は`skills/diagram-explainer/SKILL.md`にあり、そこから指す説明は`skills/diagram-explainer/references/`にあります。

## 手順

| 手順 | 誰が | 何をするか |
|---|---|---|
| 調べる | エージェント | 規格、API、プロトコルの説明では、公式の仕様を読み、版と読んだ日を記録します。あなたの仕組みの説明では、あなたが指したコードと文書を読みます |
| 構成を立てる | エージェント | 読み手が知りたいことを挙げ、ページ、節、節ごとの図を決めます |
| 構成を決める | あなた | 合うまで節や図を直します |
| 書く | エージェント | ページ、節、本文、図、グラフ、表を、JSONで書きます |
| 組む | エージェント | プラグインのスクリプトで、JSONを1つのHTMLファイルにします |
| 確かめる | エージェント | 資料の検査を回し、出た指摘をすべてJSONで直して組み直します |
| 読み直す | エージェント | 数字と単位、図が本文のとおりかを読み直し、すべての節をパソコンの幅とスマホの幅で見ます |
| 直す | あなたとエージェント | 直してほしい所を伝えると、エージェントがJSONを直して資料を組み直します |

## 資料に入る物

| 部分 | 中身 |
|---|---|
| 目次 | 今のページの節を並べます。押した節だけを出します |
| ヘッダー | 話題が2つ以上ある時に出ます。題、ページごとのタブ、日付、PDFのボタンを持ちます |
| 節 | 本文と図と、要点の数字、見比べるカード、補足と注意、前と後の比較、表、コード、畳んだ詳細を持ちます |
| スマホの画面 | 今の節の名前と、目次を横から出すボタンの帯を出します |
| 印刷の形 | ヘッダーと目次を隠し、すべての節を1枚に1節ずつ順に並べます。PDFのボタンで、今のページか全部のページかを選んで刷ります |

図はすべてページの中に描きます。

| 図 | 向く中身 |
|---|---|
| HTMLで描く箱と矢印 | 部品のつながり、流れ、層、受け持ち |
| 時刻の帯 | 開いている時間と、物事が起きる時刻を段ごとに並べます |
| 量の棒 | 上限に対する量と、削る前と後です |
| 数字のグラフ | 2つ以上の数字の大小を比べます |
| 期間の図 | 期間を年の軸に並べます |
| 段の並び | 呼ぶ物、関門、動かす側のように、項目の多い手順を段に並べます |

資料のボタンや見出しの文字は、資料の言語 (英語か日本語) に合わせます。

## あなたが見る前に確かめる物

`scripts/check.py`は、次のすべてが満たされるまで資料を落とします。

- ネットから何も読み込みません。URLから読むスクリプト、スタイルシート、Webフォント、画像を持ちません
- すべての節が図を持つか、図を置かない理由を書いています
- 目次、節の見出し、ヘッダーのタブ、ページが食い違いません
- すべての図が説明書きを持ち、1つのページの中で図の番号が飛ばず、重なりません
- 表のすべての行が、見出しの行と同じ数のセルを持ちます
- 畳んだ詳細を開いたまま配らず、題と最初の節の間には導入の文1つだけを置きます
- idが重ならず、図の中の参照がすべて解決します
- 用語表で言い換えると決めた語が、本文にも図にも残っていません
- ブラウザーがある時は、いくつかの画面の幅で、読み込みの間にページの高さが動かず、横にはみ出さないことを確かめます

日本語の資料は、同梱の語の一覧でも本文を確かめます。回りくどい言い回し、読み手が知らない語、本文に残った作業の記録、表記の揺れ、見出しの読点、識別子を主語にした比喩の動詞が対象です。
段落と文の長さ、同じ文の繰り返し、図にだけ出てくる名前は数えるだけで、落としません。

## ファイルを置く場所

資料ごとに、作業中のプロジェクトの`docs/explainers/<名前>/`か、あなたが指したフォルダーを持ちます。
フォルダーには、元になる`content.json`、段の並びの定義 (ある時)、用語表 (ある時)、出来上がった`<名前>.html`を置きます。
PDFを頼んだ時は、HTMLファイルの隣に書きます。
ほかの場所には何も残さず、確かめる時の一時ファイルは確かめ終わった時に消します。

## 実行する物とつなぐ先

- あなたが指したコードと文書。公開されている題材では、エージェントのWeb検索とWebページの読み込みを使い、検索には題材、規格、製品、提供元の名前だけを入れます
- 資料を組む時と確かめる時の`python3`
- 崩れを測る時とPDFを作る時の、パソコンに入っているChromium系のブラウザー (Chrome、Chromium、Edge、Brave、PlaywrightのHeadless Shell)。画面に出さずに動かし、使い捨てのプロフィールを使って、終わったら消します。`DIAGRAM_EXPLAINER_BROWSER`で使うブラウザーを選べます

このプラグインは何もインストールせず、書いた資料もネットから何も読み込みません。
