About this page

What is listed

Caches that tools rebuild, build output that git ignores, the Trash, old logs and installers, large and duplicate files, apps you have not opened for 90 days, dev servers left running after their session ended, heavy processes, login items, and running containers.

Why some rows cannot be picked

A row is in use when a live agent session or an open terminal runs it, or when a running program works in the same project. Close that session or program, and ask the agent to scan again.

What is never touched

Sync folders such as iCloud Drive, Dropbox, Google Drive, and OneDrive, Windows drives under WSL, files git tracks, Docker volumes, and anything that needs an administrator password.

What happens next

The agent frees only what you picked, then reports the free disk space, memory, and load before and after, measured on this computer.
