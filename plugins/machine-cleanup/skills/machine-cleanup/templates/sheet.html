About this page

What is listed

Caches that tools rebuild, build output that git ignores, the Trash, old logs and installers, large and duplicate files, git projects nobody has used for 30 days, apps you have not opened for 90 days and files left behind by removed apps, tool versions no project uses, downloaded AI models, dev servers left running after their session ended, heavy processes, login items, and running containers.

Why some rows cannot be picked

A row is in use when a live agent session or an open terminal runs it, when a live agent session runs inside it or inside its app, or when a live agent session or another running program works in the same project. Close that session or program, and ask the agent to scan again.

What the groups mean

Recommended rows are rebuilt the next time they are needed, or were already thrown away or left unused for 30 days. Check first rows are your own files, apps, and login items, which you can put back. Careful rows are running programs and containers, whose work stops when they end.

What the overview shows

What can be freed by kind and by group, the whole disk and memory, the largest items, and the processes using the most memory and CPU. Press a part of a chart to open its tab, or a bar to see that row. Each row's i button shows its reason, location, and command.

What is never touched

Sync folders such as iCloud Drive, Dropbox, Google Drive, and OneDrive, Windows drives under WSL, files git tracks, Docker volumes, and anything that needs an administrator password.

What happens next

The agent frees only what you picked, then reports the free disk space, memory, and load before and after, measured on this computer.
