# 仕組み

[English](how-it-works.md) · 日本語

このページは、Conveyが読む物、動かす物、残す物と、`convey.py`が確かめる物を書きます。
文を書くのはエージェントで、`skills/convey/scripts/`の道具は文を確かめて写すだけです。

## スキルのファイル

パスは`skills/convey/`から見た形です。

| パス | 中身 |
|---|---|
| `SKILL.md` | 決まりと、内容を集めて文に載せる事を選び、文を見せるまでの5つの手順 |
| `references/types.md` | 7つの型と、結論から始まる各型の項目の順 |
| `references/filler-phrases.tsv` | `check`が注意として出す日本語と英語の決まり文句と、それぞれの直し方 |
| `scripts/convey.py` | `check`、`copy`、`formats`の3つのコマンド |
| `agents/openai.yaml` | Codexでのスキルの名前と既定の頼み方 |
| `tests/test-convey.sh` | プラグインの検査 |

## checkが見る物

`convey.py check --to <貼る先> [ファイル]`は、ファイルから文を読みます。ファイルを渡さない時と`-`を渡した時は標準入力から読みます。
字数を出し、見つけた物ごとに`L<行> <種類>: ...`の形で1行を出し、最後に`ready to paste`か`not ready`を出します。

| 種類 | 終了コード | 意味 |
|---|---|---|
| `over the limit` | 1 | 文が貼る先の上限より長い。続く行が、コードブロックの外の空行で分けた時の各部分を出し、どの部分も上限に収まる |
| `format` | 1 | 貼る先で書いた記号がそのまま見える書式か、最初の行が`Subject:`の件名の行でないメール |
| `secret` | 1 | GitHub、AWS、Slack、OpenAI、Anthropic、Googleの鍵、webhookのURL、秘密鍵、JSON Web Token、パスワード入りのURL、`password=`のような名前の後に書いたパスワードかトークンに見える値 |
| `private` | 1 | `/home/`の下のような利用者のホームフォルダの下のパス、メールアドレス、電話番号 |
| `warn` | 0 | `references/filler-phrases.tsv`の決まり文句、短い項目名とコロンで書いた行、コードとURLとパスとメンションの外の和文と英字や数字の間の空白、貼る先で普通は使わない絵文字 |

見つけた物は、行と種類だけを出し、値そのものは出しません。
字数は、末尾の空行を除いた後のUTF-16の単位で数えます。絵文字には2と数える物があり、数え方は安全な側に寄ります。
上限は、Slackが1通をこの長さまでに収めるよう勧める4,000字、Discordの有料プランでない時の上限の2,000字、GitHubのcommentの上限の65,536字です。
`convey.py formats`は、貼る先ごとに上限と描かない書式を出します。

## 動かす物と繋ぐ先

- エージェントはスキルのフォルダから`python3 convey.py`を動かします。読み込むのはPythonの標準ライブラリだけです
- `copy --to <貼る先> [--lines A-B] [ファイル]`は、文か、A行目からB行目までに同じ確かめを回し、直す行があれば1で断ります。無ければ`PATH`から`pbcopy`、`wl-copy`、`xclip`、`xsel`、`clip.exe`の順に探し、最初に成功した道具へ文を渡します。`clip.exe`にはUTF-16で渡します。1つも見つからない時と全て失敗した時は、`not copied`を出して3で終わります
- エージェントが`gh issue view`、`gh pr view`、`git log`、`git show`を動かすのは、Issue、PR、commitを指した時だけです。`gh`はあなたのサインインを使います
- 日本語の文を書く時に`japanese-writing`のスキルが入っていれば、エージェントはそのスキルの決まりと`references/connecting.md`を読みます。`references/connecting.md`は、長い文を区切って短い文を接続詞で結ぶ手引きです。ほかのプラグインからはこれ以外を読みません
- どこへも送らず、プラグインが投稿することはありません。道具は文を1つ読み、端末に出すだけです

## 残す物

何も残しません。
文は、あなたが名指したファイルか、プロジェクトの外の一時ファイルに置き、一時ファイルは終わる時にエージェントが消します。
クリップボードの中身は、あなたが別の物を写すまで残ります。
