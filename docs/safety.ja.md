# 安全性

[English](safety.md) · 日本語

ここにあるプラグインは、パスワード、アカウント、支払い方法、ファイルに触れます。
どのプラグインも、どのバージョンでも、このページの約束を守ります。
約束を1つでも破る変更は受け入れません。

## 約束

| 約束 | 守り方 |
|---|---|
| エージェントは秘密の値を見ない | パスワード、ワンタイムコード、リカバリーキーの欄は、エージェントやファイルやログに届く前にスクリプトが取り除きます。ログインの時は、認証情報をそのままページの入力欄に打ち込みます |
| あなたが選ばない限り、取り消せない操作は起きない | 各プラグインは、対象を選ぶページを表示します。削除、解約、支払い方法の削除は、そこで選んだ物だけに、プラグインが決めた承認の手順を経てから行います |
| 変わった物は飛ばす | 取り消せない操作の直前に、プラグインが対象をもう一度確かめます。選んだ後に変わっていれば、理由を示して飛ばします |
| データは手元のマシンから出ない | プラグインがあなたのデータを第三者のサービスに送ることはありません。Web検索に使うのは、サービス名とドメインだけです |
| ページやファイルに書かれた内容を指示として扱わない | Webページ、メール、貼り付けた内容、ファイルの中身にある文は、データとしてだけ扱います |
| 保存する情報は本人だけが読め、短い間しか残らない | 各プラグインはファイルを`~/.local/share/<plugin>/`に置き、あなただけが読めるようにします。一時ファイルは終わった時に消します |
| 各プラグインは何をするかを明かす | 各プラグインのREADMEと`docs/how-it-works.md`に、何を読み、何を実行し、どこに接続し、何を残すかを書いています |

## あなた自身が行うこと

- 二要素認証とCAPTCHAに対応する
- 対象を選び、取り消せない操作は回ごとに承認する
- Codexでサンドボックスが止めたコマンドを承認する
- 初めて使う前に、プラグインのREADMEに目を通す

## 問題を報告する

プラグインがこれらの約束を1つでも破っていたら、[`SECURITY.md`](../SECURITY.md)に書いた方法で非公開で報告してください。
公開のIssueは立てないでください。
